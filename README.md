# bd_algoritmos

Algoritmos em C++ e Python.

Comandos de compilação:

## C++
### Compilação
```g++ -std=c++20 -DLOCAL -O2 -lm -static -Wall -Wextra -Wshadow -Wconversion -Wlogical-op -o main```

### Execução (Linux)
```./main < in.txt```

### Execução (Windows)
```main.exe < in.txt```

## Python
### Linux
```python3 main.py < in.txt```

### Windows
```py main.py < in.txt```
