# bd_algoritmos

Algoritmos em C++ e Python.

## C++
### Compilação
```bash
g++ -std=c++20 -DLOCAL -O2 -lm -static -Wall -Wextra -Wshadow -Wconversion -Wlogical-op -o main
```

### Execução (Linux)
```bash
./main < in.txt
```

### Execução (Windows)
```bash
main.exe < in.txt
```

## Python
### Linux
```bash
python3 main.py < in.txt
```

### Windows
```bash
py main.py < in.txt
```
